# Environment Setup Guide

This guide walks you through the process of setting up TechZone environments to support various Level 4 watsonx.ai labs such as Custom Foundation Models, AutoAI RAG, Base Installations, and InstructLab.

## 1. Setting up watsonx.ai Environments for Practitioners

Each lab uses a certified TechZone image. Be sure to use the right image or you won’t be able to complete the lab.

| Lab Name | Required Image |
|----------|----------------|
| Base Installation Lab & watsonx.ai Installation Lab | watsonx.ai and watsonx.data Level 4 Install |
| Custom Foundation Model | watsonx.ai for custom models (Student ID version) |
| AutoAI RAG | watsonx.ai and watsonx.governance (Student ID) + watsonx.data Development Lab |
| InstructLab | InstructLab opensource CLI v0.21.0 |

## 4. Making a TechZone Reservation

### Reservation Steps:

1. Choose **Reserve now** or schedule for later
![](../images/217/reservation_img_12_1.png)
2. Set name of reservation (e.g., `john_doe_foundation_model`)
3. Purpose: **Education**
4. Description: e.g., `Complete L4 Custom Foundation Model Lab`
5. Choose a preferred geography: `us-south`, `eu-de`, `jp-tok`, etc.
![](../images/217/reservation_img_13_1.png)
6. Optional: Set a shorter reservation time
![](../images/217/reservation_img_13_2.png)
7. If prompted, select **Install Db2 = No**
![](../images/217/reservation_img_13_3.png)
![](../images/217/reservation_img_14_1.png)
8. For InstructLab: Disk = 500 GB, VM = 16 vCPU / 64 GiB
![](../images/217/reservation_img_14_2.png)
9. Add notes if needed
![](../images/217/reservation_img_14_3.png)
10. Accept Terms → Click **Submit**
![](../images/217/reservation_img_15_1.png)
11. Wait for provisioning email (~10–15 min)
![](../images/217/reservation_img_15_2.png)
12. You will often need to bring up this page as it contains important information on how to use the image properly
![](../images/217/reservation_img_16_1.png)

## 5. After a Successful Reservation

### 5.1 Using the Student ID Version

Used in: Custome Foundation Model/AutoAI RAG

_Not used in: Base Install / InstructLab._

### Login Instructions:

1. Go to [My Reservations](https://techzone.ibm.com/my/reservations)
2. Click your reservation
3. Log out of any existing IBM Cloud sessions: [Logout](https://cloud.ibm.com/logout)
4. Use IBM Cloud login credentials shown in your reservation
5. Navigate: Resource List → AI / Machine Learning
6. Click: `watsonx.ai Studio`
7. In dropdown: Choose **IBM watsonx**
8. Close intro popups
9. Go to “Recent Work” and use the sandbox project
